# AI Testcase Lab

一个以手写代码为主的 AI 测试用例平台学习项目。

目标：每天约 2 小时，用 4 周逐步实现核心流程，并能够解释请求处理、数据库读写和模型调用的过程。该时间为学习目标，按实际进展调整。

## 核心范围

需求输入 → 功能点提取与确认 → 用例生成 → 人工编辑、采纳 → 入库与 Excel 导出。

- 项目管理：创建和查看项目。
- 需求输入：粘贴并保存需求文本。
- 功能点：模型提取、手动修改、确认。
- 用例生成：标题、前置条件、步骤、预期结果。
- 用例管理：查看、编辑、采纳、删除。
- 导出：Excel 文件。

## 四周目标

| 周次 | 目标 |
| --- | --- |
| 第 1 周 | 学习 FastAPI 与 SQLite，实现项目和需求的基础读写 |
| 第 2 周 | 接入模型，实现功能点提取、校验和确认 |
| 第 3 周 | 完成用例生成、管理和 Excel 导出 |
| 第 4 周 | 自己编写关键接口测试，修复问题，整理演示和说明 |

## 学习方式

- 从 FastAPI 和 SQLite 的基础开始，代码由学习者逐步手写。
- 每次围绕一个小功能，先明确输入和预期输出，再实现和验证。
- 结合具体请求，理解参数如何进入函数、数据如何保存、响应如何返回。
- AI 助手负责解释、拆解任务和协助排错；需要代写实现时再明确提出。
- 测试代码也由学习者逐步编写，保留自己的实践记录。
